# 나의 ETF — GitHub Pages 아이폰 웹앱

**별도 서버나 Render·Cloudflare 가입 없이 GitHub Pages에서 사용하는 ETF 포트폴리오입니다.** 화면을 열거나 **시세 조회** 버튼을 누를 때 네이버 금융에서 ETF 가격을 가져와 수익을 계산합니다. 주기적 작업이나 GitHub Actions 시세 수집은 사용하지 않습니다.

## 처음 한 번: GitHub Pages 켜기

1. [이 저장소의 Pages 설정](https://github.com/bunnyliu/ETF_profit/settings/pages)을 엽니다. 저장소의 **Settings → Pages**로 들어가도 됩니다.
2. **Build and deployment → Source**에서 **Deploy from a branch**를 선택합니다.
3. **Branch**는 **main**, 오른쪽 폴더는 **/docs**를 선택하고 **Save**를 누릅니다.
4. GitHub의 배포가 끝나면 설정 화면의 **Visit site**를 누릅니다. 기본 프로젝트 주소는 아래와 같습니다.

   **https://bunnyliu.github.io/ETF_profit/**

설정 저장과 배포가 끝나기 전에는 주소가 열리지 않습니다. 변경사항을 main에 올리면 Pages가 다시 배포합니다. GitHub Pages를 사용할 수 있는 저장소/계정 플랜이 필요합니다. 비공개 저장소에서 Pages 메뉴에 업그레이드 안내가 표시되면 플랜 제한이며, 저장소 공개 여부를 검토해야 합니다. 이 앱이 저장소의 공개/비공개 설정을 자동 변경하지는 않습니다. 코드나 과거 커밋에 개인 파일이 있는지 확인 없이 저장소를 공개하지 마세요.

## 아이폰 홈 화면에 추가

1. 아이폰 **Safari**에서 위 사이트 주소를 엽니다.
2. **공유 → 홈 화면에 추가**를 선택합니다. **웹 앱으로 열기**가 보이면 켭니다.
3. 홈 화면의 **나의 ETF** 아이콘으로 실행합니다.

앱 화면과 계산은 아이폰에서 실행됩니다. PC를 켜 둘 필요가 없습니다. 홈 화면 설치는 HTTPS가 필요하며, 실제 아이폰 설치는 배포 후 확인하세요.

## 사용 방법

- **종목 추가**: 종목명/코드를 검색하고 평균 취득가와 투자금액을 입력합니다. 목록을 가져오지 못했을 때는 코드를 직접 입력할 수 있습니다.
- **시세 조회**: 그 순간 네이버에 공개 ETF 시세를 요청합니다. 장 마감·휴장 때는 제공처의 마지막 가격이 표시됩니다. 제공처 가격은 실제 체결가와 차이가 날 수 있습니다.
- **수정·삭제**: 종목 카드에서 변경합니다. 저장하면 즉시 재계산하며, 시세를 다시 요청하지 않습니다.
- **CSV 가져오기**: 기존 PC 스크립트 옆의 `my_portfolio.csv`를 선택합니다. 같은 종목코드는 덮어쓰고 나머지 종목은 유지합니다.
- **CSV 백업**: 현재 기록을 파일로 저장합니다. UTF-8 BOM, 기존 열 이름 `종목코드,종목명,취득가,투자금액`을 유지합니다. 잘못된 CSV는 전체를 거절합니다.

## 투자 기록은 어디에 저장되나요?

종목코드·종목명·취득가·투자금액은 **현재 브라우저의 localStorage**에 저장됩니다. 이 앱은 투자 내역을 GitHub나 시세 서버로 보내지 않으며, GitHub에 개인 CSV를 올릴 필요가 없습니다. 조회 요청은 개인 내역과 관계없이 공개 ETF 전체 목록을 읽습니다.

**PC, 아이폰 Safari, 홈 화면 앱의 저장공간은 자동 동기화되지 않습니다.** iOS 버전/설치 방식에 따라 Safari와 홈 화면 앱의 기록도 별개일 수 있습니다. 홈 화면 앱에 직접 기록하거나 CSV로 옮겨 주세요. 브라우저 데이터 삭제·기기 변경·비공개 브라우징 종료 시 기록을 잃을 수 있으므로 CSV를 정기적으로 백업하세요. 같은 주소를 쓰는 다른 브라우저 창끼리는 저장 변경이 반영됩니다.

웹사이트의 화면과 코드는 공개되지만 보유 내역은 그 주소에 공개되지 않습니다. 기기 자체의 잠금 기능으로 기록을 보호하세요. 서버 암호 로그인은 GitHub Pages 버전에서 사용하지 않습니다.

## 조회 실패·오프라인·계산 기준

- 조회가 실패하면 **마지막 성공 가격과 원래 조회 시각**을 유지하고 실패 안내를 표시합니다. 성공 시각을 새로 찍지 않습니다.
- 오프라인에서는 캐시된 앱 화면과 마지막 가격을 쓸 수 있습니다. **최신 시세가 아니라는 안내**를 표시하며, 처음 방문은 온라인 연결이 필요합니다.
- 가격이 없는 종목이 하나라도 있으면 전체 평가금액·손익·수익률을 `—`로 표시합니다. 누락 가격을 0원이나 손실로 계산하지 않습니다.
- 수량 = 투자금액 ÷ 평균 취득가. 평가금액 = 수량 × 조회 가격. 손익 = 평가금액 − 투자금액. 소수 수량을 허용하는 원본 계산을 유지하므로 실제 정수 보유 수량과 차이가 날 수 있습니다. 수수료·세금·분배금은 제외합니다.
- 브라우저 저장이 실패하면 저장했다고 표시하거나 기존 내역을 덮어쓰지 않습니다. 저장 원본을 읽지 못하면 변경을 중지하고 백업 기능으로 원본을 내려받을 수 있습니다.

## 개발 및 검증

`docs/`가 완성된 정적 사이트입니다. Node 20 이상으로 핵심 로직 테스트를 실행할 수 있습니다.

```bash
node --test tests/test_portfolio.mjs
python3 -m http.server 8502 --directory docs --bind 127.0.0.1
```

정적 파일은 모두 상대 경로를 사용하므로 GitHub 프로젝트 경로 `/ETF_profit/` 아래에서도 실행됩니다. manifest·아이콘·service worker를 포함합니다. Service worker는 앱 파일만 저장하고 시세 요청을 가로채지 않습니다.

시세는 네이버가 제공하는 `_callback` JSONP 응답으로 가져옵니다. 일반 fetch CORS가 필요하지 않습니다. 외부 시세 스크립트는 `sandbox="allow-scripts"` iframe의 별도 출처 안에서 실행하며, 투자 내역이 있는 상위 문서·브라우저 저장소에 접근하지 못합니다. 메시지 발신 iframe과 요청별 토큰을 확인하고 데이터 형식을 검증합니다. 네이버 정책·API 형식 변경으로 조회가 제한될 수 있으며, 외부 CORS 프록시는 사용하지 않습니다.

기존 Python 서버 구현(`app.py`, `market.py`, `templates/`, `static/`, Dockerfile)은 남겨 두었습니다. GitHub Pages에는 `docs/`만 배포되며 Python은 필요하지 않습니다. 기존 Python 테스트를 실행하려면 `requirements-dev.txt`를 설치하고 `python -m pytest -q`를 실행하세요.
